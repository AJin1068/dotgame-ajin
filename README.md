# 꿀벌 꿀 모으기

꿀벌이 방향키로 꽃 5송이를 돌며 소나기가 오기 전에 꿀을 모으는 화면 하나짜리 도트 게임.

## 실행

```
python3 -m http.server 8000
```

그 다음 http://localhost:8000 을 연다. `file://`로 직접 열면 ES module이 브라우저에 막혀 동작하지 않는다.

## 조작

- 타이틀: 아무 키나 누르면 레벨 1이 시작한다 (누른 키로는 벌이 움직이지 않는다).
- 방향키 ↑↓←→: 한 번 누를 때 한 칸 이동 (누르고 있어도 한 칸, 이동 중 입력은 버림)
- F5: 새로고침. 타이틀로 돌아간다. 성공·실패 화면에서 다시 하려면 누르며, 키를 눌러 레벨 1부터 다시 시작한다.

## 규칙

- 레벨은 3개. 레벨마다 꽃 5송이가 있고, 꽃 위에 서 있으면 자동으로 초당 꿀 1씩 모은다 (버튼 없음).
- 꽃 5송이의 꿀을 모두 모으면 레벨 성공. 레벨 1·2는 3초 뒤 다음 레벨이 시작되고, 레벨 3은 최종 화면에서 멈춘다.
- 말벌 칸에 도착하면 실패. 말벌은 움직이지 않고 레벨 1·2·3에 1·2·3마리다.
- 레벨 시작 후 90초가 지나면 소나기가 와서 실패.

## 테스트

```
node --test test/          # 단위 시험 62개
node e2e/key-sequence.js   # 가짜 DOM 위에서 키 입력 재생
node e2e/chrome-render.js  # 서버가 :8000에서 떠 있어야 하고 macOS Chrome 필요
```

e2e 스크립트는 사람의 브라우저 확인을 대체하지 않는다.

## 파일 구성

- `index.html`: 캔버스 페이지
- `src/main.js`: 입력·그리기·게임 루프
- `src/logic.js`: 순수 함수 로직 (이동·채집·소나기·레벨 진행)
- `src/levels.js`: 레벨 1~3 맵
- `src/sprites.js`: 스프라이트 픽셀 배열
- `src/strings.js`: UI 문구
- `src/sound.js`: 효과음
- `test/`: 단위 시험
- `e2e/`: key-sequence.js, chrome-render.js

## 기획서

`GAME_DESIGN.md`가 유일한 기획서다. 9장에 수용 기준이 있고, 각 기준 끝의 표시가 사람의 브라우저 확인 상태를 나타낸다.

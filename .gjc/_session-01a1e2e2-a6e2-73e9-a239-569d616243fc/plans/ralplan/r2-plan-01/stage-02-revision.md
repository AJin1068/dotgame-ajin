### 옵션
**옵션 A (채택): `tick(state, nowMs)` 시간 적분 순수 함수.** 꽃마다 `collectedMs`. 장점: 경계 정확 시험, 프레임 지터에 안 흔들림, canvas 분리. 단점: handleKey가 먼저 tick을 불러야 하고 시계 불일치 가드가 필요, 상태 필드 증가.
**옵션 B (기각): main.js setInterval(1000)으로 매초 차감.** 로직이 시계에 새어 단위 시험 불가, "도착 후 정확히 1초" 규칙을 못 지킨다. 결정 동인 1 위반.

**결과 표시** (a) 채택: 전체 화면 배경(성공=팔레트 1, 실패=팔레트 7) + 가운데 팔레트 0 패널 80×80 + 큰 스프라이트 64×64(1픽셀=8px). 스프라이트 몸통색이 배경색과 같아도 패널이 분리해 보인다. (b) strings.js 문구 배너: R3 UI 침범 → 기각. (c) 테두리만 번쩍: 인식 어려움 → 기각. (d) 패널 없이 배경+스프라이트: 몸통이 배경에 묻힘(Arch 지적) → 기각.
**꿀 막대** (a) 채택: 꿀 1단위 = 노란 칸 1개, 어두운 바탕이 전체 칸 수(=꽃의 꿀 양)를 보여줌. (b) 연속 막대(칸 구분 없음): 눈으로 셀 수 없음 → 기각. (c) 숫자 표시: UI 문구 침범 → 기각.
**꿀 양 부호화** (a) 채택: 격자에는 `F`만, 읽기 순서(위→아래, 같은 줄은 왼→오)로 5·6·7·8·9 (`LEVEL_1_HONEY`). 불변식: F 개수 = 꿀 목록 길이, 아니면 createState가 throw. (b) 격자에 숫자: 4장 기호 F와 어긋남 → 기각. (c) 좌표 표: AGENTS 위반 → 기각.

### 3-7. 8장 기술 스펙 — e2e 설명 갱신과 한계 문장
- key-sequence.js: R1 기준 1~4(18개 검사)에 더해 R2 기준 5~11을 같은 방식(가짜 DOM, 합성 keydown, 가짜 시계)으로 재생. 꿀 칸은 fillRect(2×4px, 팔레트 1)를 세어 읽고, 결과 화면은 480×320 fillRect의 색으로 읽는다. 벌은 "프레임에서 마지막 50개의 4×4 rect"로 찾고 BEE_SPRITE와 좌표·색이 일치하는지 확인한다. 못 하는 것: R1과 동일 + 실제 꽃 모양의 보기 좋음·칸 가독성, 실제 시간 흐름의 체감, 실제 rAF 타임스탬프와 performance.now 사이의 불일치(로직 시험은 합성 시각만 쓴다).

## 9. Escalation / Risk Gate
같은 확인 항목 2회 연속 X이거나 한 시도 6회 초과 반복 시 중단하고 replan-N. 사람이 막대를 여전히 못 센다고 하면 칸 크기·피치 변경은 기획서 4장 수정이므로 replan 대상. 스크린샷 게이트의 단색 거절은 리더가 처리.

## 10. Risks and mitigations
1. R1 e2e 벌 식별 회귀(꽃이 팔레트 1~3 4×4 rect 사용): 마지막 50개 + BEE_SPRITE 일치 검증 + 그리기 순서 계약 주석. 순서가 깨지면 크게 실패.
2. R1 경로 회귀: 시작 행·열 비움 원칙 + 맵 시험(1번).
3. 시계 불일치(rAF ts vs performance.now): `nowMs <= lastMs` 가드로 역행 방지, 합성 시험(12번). 실제 불일치는 사람 확인으로만 덮음(정직하게 명시).
4. 떠나는 순간 채집분 손실: handleKey가 tick 후 이동(13번).
5. 숨은 탭: dt를 그대로 반영, 꽃 위에서 숨으면 한꺼번에 모이거나 즉시 성공할 수 있음. 보정 규칙을 안 넣는 것은 에이전트 제안; 8장에 문장으로 남기고 15·16번 시험, 사람은 참고로만 확인.
6. 칸이 너무 작음(2×4px): 어두운 바탕이 빈 칸을 보여주고 확대 허용을 기준에 적음. 그래도 못 세면 replan.
7. 막대가 벌 스프라이트 일부를 가림: 의도(서 있는 동안 보이게). 5·6 확인에서 판독 가능한지 본다.
8. 결과 화면이 스크린샷 단색 게이트에 걸릴 위험: 패널·스프라이트로 단색이 아님; 게이트는 리더 소관.
9. 정수/부동소수: collectedMs는 ms 누적, floor로 경계 정확. 시험값은 정수.
